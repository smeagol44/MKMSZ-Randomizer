# MKMSZR Wiki source

This directory is the version-controlled source for the living/current MKMSZR GitHub Wiki.

The Wiki is the current documentation and research-synthesis surface. The Library folder `MKMSZR Research` preserves durable evidence, historical canonical reports, Ghidra/static-analysis material, catalogs, screenshots, RAM evidence, handoffs, and archives.

Changes merged to `main` are published by the Wiki sync workflow.
